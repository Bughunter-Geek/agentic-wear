Agentic Wear Cloud Receiver / Mac companion 0.3.15 — Alpha 1

Also called Relay. This ZIP includes the matching Mac bridge, Chrome receiver,
native messaging helper and dependency licenses. Watch version: 0.6.36/build118.
Use Node.js22+ on macOS and your existing compatible signed-in Codex/Chrome,
relay/Firebase deployment and authenticated Watch pairing.

Enable Agentic Wear Cloud Receiver in Chrome. Open your own Dot, end calls,
open the popup and choose Connect this Dot. No Dot is selected by default.
Selection stays in Chrome extension-local storage; missing/malformed/mismatched
selection blocks Dot access. The companion's private target must match it.
Keep private targets, bootstrap credentials and pairing outside downloads.

Update existing files in place after privately backing them up. Preserve the
public key/ID, native-host registration, Chrome storage, signing and pairing.
0.3.15 supersedes both prior receiver version series. Never remove an existing
extension to apply this update. Reload/restart only after all calls end.
See docs/mac-package-setup.md for explicit preview-first native-host setup;
no installer is run merely by extracting this ZIP.

Local voice uses native Codex; Dot uses the selected Chrome native call;
ordinary cloud voice uses the scoped Mac companion. Substantive cloud requests
and replies appear in the selected thread; the full voice transcript does not.
Approval cards are alert-only in Alpha1: decide in Codex. Known relay-flood and
large-Unicode-history availability issues are deferred to Alpha1.1.
